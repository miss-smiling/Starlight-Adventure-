# Development Status - Starlight Adventure

A children-friendly space-agency simulation built with Godot 4.7.2.

## Current state (working build)

**Boots cleanly headless. All 93 logic tests pass. All screens and task
modules instantiate in the integration self-test.**

- Backend layer (11 autoloads + 10 model scripts): complete, ~1,050 lines.
- Campaign data: complete (2026 full campaign, 2027-2031 single missions,
  dialogues, crew, professions, achievements) generated by `tools/build_data.py`.
- UI layer (21 scripts): complete.
  - `scripts/ui/ui_kit.gd` - theme + shared widget library.
  - `scripts/app.gd` - screen router + code-registered input map
    (WASD/arrows, E interact, Escape pause).
  - 10 screens: main menu, new game, profession select, mission select,
    settings, achievements, leaderboard, archive, gameplay, debrief.
  - 8 profession task modules covering all 15 data patterns:
    route, switches, burn (astronaut); build, inspect, repair (engineer);
    measure (physicist); figure (mathematician); procedure (biologist);
    triage (medical); tune, channels, link (comms); priority, decision (director).
  - Dialogue view with typing effect, portraits, choices, comms journal.

## Gameplay loop implemented

Mission start -> briefing dialogue -> walk 1280x640 room -> talk to 2 crew
-> duty station task (profession config from JSON) -> emergencies trigger
recovery (RecoveryManager + emergency dialogue) -> finish station plays
ending dialogue -> report -> score/grade -> debrief -> achievements ->
leaderboard. Mid-mission saves preserve objectives, flags, mistakes,
decisions, dialogue history and player position. Replays never touch the
real save.

## Not implemented (deferred by design)

- Real artwork: everything is colored placeholders. Drop PNGs into
  `assets/` later; loaders fall back to placeholders when files are absent.
- Audio.
- Screens built in code (only `app.tscn` is a scene file), per plan.

## Running

- Open the project in Godot 4.7.2, or run the editor executable.
- Tests: `godot --headless -s res://tests/system_test.gd`
- Integration: `godot --headless --path . -- --selftest`
