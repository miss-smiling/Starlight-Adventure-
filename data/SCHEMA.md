# Starlight Adventure data schema

Generated by `tools/build_data.py`. Edit the Python in `tools/`, then rebuild and run `tools/check_data.py`.
Do not hand-edit the JSON, it will be overwritten.

## Files
- professions.json: array of {id, name, color, short, duty, tools[]}
- crew.json: array of {id, name, profession, color, bio}. One crew member per profession.
- dialogues.json: id -> {lines[], next?}. A line is {speaker, text} or {choices[]}.
  A choice is {text, flag?, value?, lasting?, goto?}. Tokens: {callsign}, {profession_name}, {year}, {warning}.
- flag_lines.json: story flag -> {speaker, text}. Append the lines for set flags to the 2031 intro.
- achievements.json: array of {id, title, text, hint}. Ids match achievement_rules.gd.
- year_YYYY.json: {year, title, campaign, tech{id,title,summary,effect}, missions[]}

## Mission
{id, title, intro, ending, duty_text, optional{text,station,fact}, learn[], team[{id,note}],
 talks{crew_id: dialogue_id}, room{name,bg,world,start,walls[],stations[]}, emergency_script[], tasks{profession: task}}

Stations: briefing, duty, npc_1..npc_3, optional, finish. Pick the 3 NPC crew from `talks`, skipping the player's own profession.

## Task (all patterns)
{pattern, title, science, hint, mistake, emergency{id, warning, fail_flag?}} plus pattern fields.
Build the result passed to MissionManager.apply_task_result from these:
  emergency_id = emergency.id, warning = emergency.warning, fail_flag = emergency.fail_flag
  mistakes[] gets task.mistake, science = task.science

Numeric parts: {id, prompt, answer, tolerance, unit}. Compatible with NumberGrader.grade_parts.

| pattern | profession | fields |
|---|---|---|
| route | astronaut | cols, rows, start, goal, hazards[], waypoints[]?, ping? (RouteGrader.valid, then check waypoints in order) |
| switches | astronaut | steps[{id,label}], order[], abort{rule, readings[{id,label,value,unit,lo,hi,ok}], should_abort} |
| burn | astronaut | parts[], timing{zone[lo,hi], speed}, given? |
| build | engineer | parts[{id,label}], order[], gauges[{..., ok}], bad_gauge, malfunction, heat? (TwistGrader.heat) |
| inspect | engineer | steps[{id,label,value,unit,lo,hi,ok}], rule, must_flag[] |
| repair | engineer | symptom, rows[{id,component,clue}], answer |
| measure | physicist | given{}, parts[], bar{zone,speed}?, verdict{prompt,options[],answer}? |
| figure | mathematician | given{}, parts[], table{prompt,columns[],rows[{id,cells[]}],answer}? |
| procedure | biologist | steps[{id,label}], order[], question, samples[{id,label,view}], answer, conclusions[{id,text,ok}] |
| triage | medical | scan_first, patients[{id,name,vitals,abnormal,note}], actions[{id,label,correct,effect}], correct_patient, correct_action |
| tune | comms | frequency{min,max,step,target,tolerance,unit}, backup_frequency, cipher{text,shift,answer}?, interference{options[],answer}? |
| channels | comms | rule, channels[{id,label,reading,expected: GO or HOLD}] |
| link | comms | parts[], budget_chars, messages[{id,text,chars,ok,flags?,lasting?,consequence?}], decode{text,shift,answer,flag_full,flag_partial}? |
| priority | director | seconds_total, events[{id,label,kind,rank,seconds,needs}] (DirectorGrader uses id and rank) |
| decision | director | prompt, choices[{id,text,result: success, success_cost, or fail, consequence, flags{}?, lasting[]?}] |

2027 tasks also carry `ai`: {says, answer: "reject", why, flag: "ai_rejected"}.
Rejecting it should set ai_rejected (lasting). TwistGrader.bad_ai("reject") is true when the helper is correctly overruled.

Decision results: put `result` inside each decision dict passed to apply_task_result,
or `costly` will not flip for success_cost.
