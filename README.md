# Starlight Adventure

A night-city mission-control game built by **Neha.R ([@miss-smiling](https://github.com/miss-smiling))** — a '20s fever' 2D pixel-art game made for young kids to explore their passion for space careers without making it BORINGGGGG!!!!!!!

Made with Godot 4.7. The web build is deployed on Vercel.
